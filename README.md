# ThisWeek.top

Public USD weekly pay-to-rank board. Bid equals rank for this week. Resets every Monday 00:00 UTC.

Domain: thisweek.top

## Week reset
weekId = Monday 00:00 UTC (YYYY-MM-DD). readBoard() clears seats when weekId mismatches.

NEXT_PUBLIC_APP_URL POLAR_ACCESS_TOKEN POLAR_WEBHOOK_SECRET POLAR_PRODUCT_ID POLAR_SERVER ADMIN_SECRET
